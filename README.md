# n8n Website Clone Using HTML and CSS

A frontend website clone inspired by the official n8n website, created using **HTML and CSS**. This project focuses on recreating the visual structure, layout, navigation, sections, typography, and overall user interface of the n8n website using core frontend technologies.

## Project Overview

This project is a practice-based frontend development project designed to improve skills in building modern and professional websites from scratch.

The website is developed without using frameworks or JavaScript, focusing entirely on **HTML for structure** and **CSS for styling and layout**.

The original n8n platform is focused on workflow automation and connecting different applications and services.
